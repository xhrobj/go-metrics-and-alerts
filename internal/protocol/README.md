# internal/protocol

Пакет содержит общие транспортные константы, которые используются Агентом и Сервером.

В пакет вынесены:

- имена HTTP-заголовков
- HTTP-типы содержимого
- значение `gzip`
- ключ `x-real-ip` для gRPC metadata

Криптографические алгоритмы и схемы остаются в профильных пакетах. Например, `rsa-aes-gcm` объявлен в `internal/encryption`, а имя транспортного заголовка `Content-Encryption` - в `internal/protocol`.
