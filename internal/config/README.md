# internal/config

Пакет содержит структуры конфигурации и функции загрузки настроек Агента и Сервера.

## Структура

- `agent.go` - конфигурация Агента и функция `GetAgentConfig`
- `server.go` - конфигурация Сервера и функция `GetServerConfig`
- `env.go` - вспомогательные функции для чтения переменных окружения

## Приоритет источников

Загрузка конфигурации сохраняет общий приоритет источников:

```text
env > flag > default
```

Пользовательские параметры запуска описаны в README соответствующих бинарников:

- `cmd/agent/README.md`
- `cmd/server/README.md`
