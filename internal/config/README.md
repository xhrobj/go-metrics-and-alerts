# internal/config

Пакет содержит структуры конфигурации и функции загрузки настроек Агента и Сервера из флагов командной строки, переменных окружения и JSON-файлов.

## Структура

- `agent.go` - конфигурация Агента, разбор флагов и переменных окружения, функция `GetAgentConfig`
- `agent_file.go` - загрузка параметров Агента из JSON-файла
- `server.go` - конфигурация Сервера, разбор флагов и переменных окружения, функция `GetServerConfig`
- `server_file.go` - загрузка параметров Сервера из JSON-файла
- `env.go` - вспомогательные функции для чтения и преобразования переменных окружения

## JSON-файл конфигурации

Путь к JSON-файлу задаётся:

- флагом `-c` или `--config`
- переменной окружения `CONFIG`

Если путь не задан, конфигурация загружается из значений по умолчанию, флагов и переменных окружения.

Примеры файлов конфигурации находятся в каталоге `configs`:

- `configs/agent.example.json`
- `configs/server.example.json`

## Приоритет источников

Загрузка конфигурации сохраняет общий приоритет источников:

```text
env > flag > JSON > default
```

Значения переменных окружения перекрывают явно переданные флаги, флаги перекрывают значения из JSON-файла, а значения из файла перекрывают настройки по умолчанию.

Для пути к самому JSON-файлу действует приоритет:

```text
CONFIG > -c/--config
```

## Параметр файла хранения метрик

Для пути к файлу хранения текущих значений метрик Сервер поддерживает две переменные окружения:

- `FILE_STORAGE_PATH` - была введена в инкременте 9
- `STORE_FILE` - была введена в инкременте 25

Если заданы обе переменные, `STORE_FILE` имеет более высокий приоритет. В JSON-файле этому параметру соответствует поле `store_file`.

Пользовательские параметры запуска описаны в README соответствующих бинарников:

- [Сервер](../../cmd/server/README.md)
