# internal/agent/config

Пакет содержит конфигурацию Агента и загружает её из значений по умолчанию, JSON-файла, флагов командной строки и переменных окружения.

## Структура

- `config.go` - `AgentConfig`, значения по умолчанию, флаги, env и `GetAgentConfig`
- `file.go` - загрузка параметров из JSON
- `env.go` - чтение и преобразование числовых переменных окружения
- `validation.go` - проверка итоговой конфигурации

## JSON-файл конфигурации

Путь задаётся:

- флагом `-c` или `--config`
- переменной окружения `CONFIG`

Пример: [`configs/agent.example.json`](../../../configs/agent.example.json).

## Приоритет источников

```text
env > flag > JSON > default
```

Для пути к JSON-файлу:

```text
CONFIG > -c/--config
```

## Валидация

После объединения всех источников проверяется итоговая конфигурация:

- адрес Сервера не пустой
- интервалы опроса и отправки положительные
- `RATE_LIMIT` положительный

Ошибки преобразования env содержат имя переменной и исходное значение.

Пользовательские параметры описаны в [README Агента](../../../cmd/agent/README.md).
