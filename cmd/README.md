# cmd

В данной директории содержится код, который компилируется в бинарные приложения.

Рекомендуется помещать сюда только код, необходимый для запуска приложения, но не бизнес-логику.

Название директории должно соответствовать названию приложения.

Директория `cmd/app_name` содержит:

- точку входа в приложение (функция `main`)
- инициализацию зависимостей (можно вынести в отдельный пакет `internal/app`)
- настройку и запуск HTTP-сервера (можно вынести в отдельный пакет `internal/router`)
- обработку сигналов завершения работы приложения

---

## Бинарные приложения проекта

В проекте два бинарных приложения:

- `agent` — собирает runtime-метрики и отправляет их на Сервер
- `server` — принимает и хранит метрики

---

## Взаимодействие компонентов

Агент периодически опрашивает runtime Go и отправляет метрики на Сервер по HTTP.

```
agent -> HTTP -> server -> storage
```

Сервер сохраняет метрики в одном из хранилищ:

- **in-memory** — хранение метрик в памяти
- **file storage** — периодическое сохранение метрик в файл
- **PostgreSQL** — хранение метрик в базе данных
