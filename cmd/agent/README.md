# cmd/agent

В директории находится точка входа Агента - приложения, которое периодически опрашивает runtime-метрики и системные метрики, сохраняет их в локальное хранилище и отправляет на HTTP-сервер сбора метрик.

Общая архитектура проекта, build info и команды Makefile описаны в [`cmd/README.md`](../README.md).

## Поведение Агента

Агент работает в несколько независимых циклов:

- отдельно собирает runtime-метрики;
- отдельно собирает системные метрики;
- формирует batch-отчёты;
- отправляет batch-ы на Сервер через очередь задач и worker pool.

Количество одновременно исходящих запросов ограничивается параметром `RATE_LIMIT`.

При временных сетевых ошибках и временных HTTP-ошибках Агент выполняет повторные попытки отправки с увеличивающимися задержками.

## Конфигурация Агента

Агент поддерживает настройку параметров через флаги командной строки и переменные окружения.

Приоритет источников конфигурации: `env > flag > default`

## Параметры запуска

- флаг `-a` или env `ADDRESS` -> адрес HTTP-сервера и порт (по умолчанию `localhost:8080`)
- флаг `-p` или env `POLL_INTERVAL` -> интервал опроса runtime-метрик в секундах (по умолчанию `2`)
- флаг `-r` или env `REPORT_INTERVAL` -> интервал отправки метрик на Сервер в секундах (по умолчанию `10`)
- флаг `-l` или env `RATE_LIMIT` -> максимальное количество одновременно исходящих запросов к Серверу (по умолчанию `5`)
- флаг `-k` или env `KEY` -> "секретный" ключ для подписи и проверки HTTP-запросов и ответов (по умолчанию ``, подпись отключена)
- флаг `--crypto-key` или env `CRYPTO_KEY` -> путь к публичному RSA-ключу (по умолчанию ``, шифрование отключено)

### Пример запуска

```bash
./agent -a=localhost:8080 -p=2 -r=10 -l=3
```

или через переменные окружения:

```bash
export ADDRESS=localhost:8080
export POLL_INTERVAL=2
export REPORT_INTERVAL=10
export RATE_LIMIT=3

./agent
```

## Подпись данных (SHA256)

Агент поддерживает подпись отправляемых данных с использованием SHA256.

Если задан параметр `-k` или переменная окружения `KEY`, Агент:

- вычисляет хеш тела HTTP-запроса с учётом ключа;
- добавляет заголовок `HashSHA256` в каждый запрос.

Если ключ не задан, подпись не используется и Агент работает в обычном режиме.

### Пример запуска с подписью

```bash
./agent -a=localhost:8080 -p=2 -r=10 -l=3 -k=secret-key
```

или через переменные окружения:

```bash
export ADDRESS=localhost:8080
export POLL_INTERVAL=2
export REPORT_INTERVAL=10
export RATE_LIMIT=3
export KEY=secret-key

./agent
```

## Graceful shutdown

Агент штатно завершает работу при получении сигналов:

- `syscall.SIGTERM`
- `syscall.SIGINT`
- `syscall.SIGQUIT`

После получения сигнала Агент:

1. останавливает циклы сбора и формирования отчётов
2. дожидается завершения уже начатого сбора метрик
3. завершает отправку задач, находящихся в очереди или уже обрабатываемых worker'ами
4. отправляет на Сервер финальный снимок метрик
5. завершает работу

Ожидание завершения отправки метрик ограничено тайм-аутом в 30 секунд.
