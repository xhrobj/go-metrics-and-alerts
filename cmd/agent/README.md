# cmd/agent

В данной директории содержится код агента — бинарного приложения, которое периодически опрашивает runtime-метрики и отправляет их на HTTP-сервер сбора метрик.

### Параметры запуска

- `-a` — адрес HTTP-сервера (по умолчанию `localhost:8080`)
- `-p` — интервал опроса runtime-метрик в секундах (по умолчанию `2`)
- `-r` — интервал отправки метрик на сервер в секундах (по умолчанию `10`)

### Пример запуска

```bash
./agent -a=localhost:8080 -p=2 -r=10
```
