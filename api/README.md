# api

В этой директории размещаются машиночитаемые контракты публичных API проекта.

- `openapi.yaml` — спецификация существующего HTTP API в формате OpenAPI 3.0.3.

Спецификация описывает фактические маршруты Сервера, форматы запросов и ответов,
модель метрик, HTTP-статусы и опциональные транспортные заголовки.
Production-код по этой спецификации не генерируется.

После добавления gRPC API здесь также будет размещён protobuf-контракт.

## Проверка

Проверить корректность OpenAPI-документа можно командой:

```bash
npx --yes @redocly/cli lint api/openapi.yaml
```
