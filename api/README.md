# api

В этой директории размещаются машиночитаемые контракты публичных API проекта.

- `openapi.yaml` — спецификация HTTP API в формате OpenAPI 3.0.3.
- `metrics.proto` — контракт gRPC API в формате Protocol Buffers.

## HTTP API

Спецификация `openapi.yaml` описывает фактические HTTP-маршруты Сервера, форматы запросов и ответов, модель метрик, HTTP-статусы и опциональные транспортные заголовки.

Production-код по OpenAPI-спецификации не генерируется.

Проверить корректность документа можно командой:

```bash
npx --yes @redocly/cli lint api/openapi.yaml
```

## gRPC API

Контракт `metrics.proto` описывает сервис `Metrics` и метод `UpdateMetrics`, который принимает единичные метрики и батчи метрик.

На основе protobuf-контракта генерируются Go-типы сообщений, интерфейсы gRPC-клиента и gRPC-Сервера. Сгенерированный код размещается в директории `internal/proto` и не редактируется вручную.

Сгенерировать Go-код можно командой:

```bash
make generate-proto
```
