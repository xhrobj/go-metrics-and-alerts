# API-контракты

В директории `api/` находятся машиночитаемые контракты внешних API проекта.

- [`openapi.yaml`](openapi.yaml) - спецификация HTTP API в формате OpenAPI 3.0.3
- [`metrics.proto`](metrics.proto) - контракт gRPC API в формате Protocol Buffers

## HTTP API

Спецификация `openapi.yaml` описывает HTTP-маршруты Сервера, форматы запросов и ответов, модель метрик, статусы ответов и опциональные транспортные заголовки.

Спецификация поддерживается вручную. Код Сервера и клиентов на её основе не генерируется.

Проверить корректность документа можно командой:

```bash
npx --yes @redocly/cli lint api/openapi.yaml
```

## gRPC API

Контракт `metrics.proto` описывает сервис `Metrics` и метод `UpdateMetrics`, принимающий пакет метрик.

На основе protobuf-контракта генерируются Go-типы сообщений и интерфейсы gRPC-клиента и gRPC-Сервера. Сгенерированный код размещается в директории [`internal/proto`](../internal/proto/) и не редактируется вручную.

Обновить сгенерированный Go-код можно командой:

```bash
make generate-proto
```
