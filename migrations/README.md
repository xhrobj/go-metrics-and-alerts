# migrations

В данной директории содержатся файлы миграций базы данных.

Миграции базы данных — это скрипты, которые позволяют:

- версионировать изменения схемы базы данных
- применять изменения в правильном порядке
- откатывать изменения при необходимости

---

## Инструмент миграций

В проекте используется библиотека: `golang-migrate`

Миграции запускаются автоматически при старте Сервера, если в конфигурации задан параметр подключения к базе данных (`DATABASE_DSN` или флаг `-d`).

---

## Проверка состояния БД

В проекте предусмотрена команда `make`, позволяющая быстро подключиться к базе данных PostgreSQL внутри Docker‑контейнера.

Подключение к базе:

```
make postgres-connect
```

Эта команда выполняет:

```
docker exec -it metrics-postgres psql -U <POSTGRES_USER> -d <POSTGRES_DB>
```

После подключения можно использовать команды `psql`:

- `\dt` — список таблиц
- `\d metrics` — структура таблицы `metrics`
- `SELECT * FROM schema_migrations;` — текущая версия миграций
- `\q` — выход из `psql`
