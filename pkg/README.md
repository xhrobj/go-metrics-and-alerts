# pkg

В директории `pkg/` находятся пакеты, API которых предназначен для использования за пределами внутренних частей проекта. В отличие от пакетов из `internal/`, Go не ограничивает их импорт другими приложениями.

Сейчас здесь находится один публичный пакет: [`pool`](pool/).

## `pool`

Пакет `pool` появился в Инкременте 22 как отдельная учебная задача по применению дженериков и `sync.Pool`.

Он предоставляет обобщенную обёртку над `sync.Pool` для переиспользования объектов, состояние которых необходимо очищать перед возвратом в пул.

Пакет не связан с worker pool Агента и не используется во время работы Агента или Сервера.

Публичный API:

- `Resetter` - интерфейс с методом `Reset()`, используемый как ограничение типа
- `Pool[T Resetter]` - типизированный пул объектов
- `New` - создаёт пул с заданной функцией создания объектов
- `(*Pool[T]).Get` - возвращает объект из пула
- `(*Pool[T]).Put` - вызывает `Reset()` и возвращает объект в пул

Пример использования находится в [`example_test.go`](pool/example_test.go).
