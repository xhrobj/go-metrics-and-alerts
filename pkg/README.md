# pkg

В директории находятся публичные пакеты, которые могут импортироваться другими приложениями без нарушения правил `internal/`.

Публичный пакет стоит размещать здесь только тогда, когда его API действительно предназначен для повторного использования вне текущего приложения.

## `pool`

Пакет `pool` содержит generic-обёртку над `sync.Pool` для объектов с методом `Reset()`.

Публичные элементы:

- `Resetter` - ограничение для типов с методом `Reset()`
- `Pool[T Resetter]` - типизированный пул
- `New` - конструктор
- `Get` - получение объекта
- `Put` - вызов `Reset()` и возврат объекта в пул

Пакет подходит для переиспользования временных объектов, состояние которых нужно очищать перед повторным использованием.
